# NewProject
This repo is to contain associated files for the New House Listing Project
This property listing project has no name yet, though the team is working on it.

## Product Objectives
To solve the problem of house and property hunting, house agents overcharge and bringing house agents closer to their audience.

## Product Capability
It ought to allow users to list houses/apartments mostly for rents (as agents etc) and for other users to easily find it on their timeline, check out accompanying pictures/videos, contact the agent who listed, inspect property physically and make payment all during the timeframe provided by the app.

## Account Creation Features
One standard account for all user, renters and agents alike
Email verification before dashboard access
Possibility of a Liveness-check feature or any other form of KYC for verified and premium user application (secondary features to be considered only when core features are fully built and tested)

## Search Feature
Search and discovery functionality for users (location, price, property type as filter options)

## Payment Between Users
Payment between users is strictly via P2P

## User Status
1. Regular users (newly created accounts, hasn't KYCed yet and therefore cannot list properties, but can order and pay for properties) -- up for debate by the team.
2. Verified Users (Users who have performed any sort of KYC and qualified to list properties)
3. Premium users (Users who subscribe for premium services, to get more tailored searches, reach more people, recommended to more accounts, have a checkmark for authenticity)

## Commission Calculation
Commission % is static percentage and calculated on property listing, an amount added to the listing price as a listing commission to the agent as they may be advised not to add extra fees to the original listing price.

## Project Monetization
This is another way revenue is intended to be generated. Ads not necessary or relevant to real estate can be placed by advertisers, the team is to serve ads in containers similar but slightly different to property/post cards to subtly show the difference between ads and posts to maintain good UX.


### Concerns 
1. Are advertisers required to have accounts to be able to place ads and monitor their ads?, if not, will there be  a separate tool for ad analytics?
2. Can we implement an ad anayltic tool within the app? (I think we can).
3. Is asking for KYC materials going to be a burden or redflag to users if so, what's the workaround?
4. Are there free compatible tools that can handle KYC data without risk of data leak or fraud?
5. Is the commission percentage meant to be controlled or to be a user decision on what their commission should be?
